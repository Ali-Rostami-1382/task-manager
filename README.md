# Daymark ☀️

**Make room for good work.**

Daymark is a calm, lightweight task manager built to make everyday planning feel a little simpler. Organize your to-dos, focus on what matters next, and keep an eye on your progress — without a complicated setup.

## ✨ Features

- **Create and edit tasks** — capture what needs doing and update it whenever plans change.
- **Priorities** — mark tasks as high, normal, or low priority.
- **Due dates** — set optional deadlines and spot overdue tasks at a glance.
- **Progress tracking** — see completed-task counts and a daily progress indicator.
- **Quick filters** — switch between all tasks, in-progress tasks, and completed tasks.
- **Search and sort** — find tasks by title or sort by when they were added, due date, or priority.
- **Persistent local storage** — your tasks stay saved in the same browser on the same device between visits.
- **Responsive layout** — designed to work across desktop and smaller screens.
- **No framework or build step** — just HTML, CSS, and plain JavaScript.

## 🚀 Run it locally

Daymark is a static front-end project, so there is no package installation or build process.

1. Clone the repository:
   ```bash
   git clone https://github.com/Ali-Rostami-1382/task-manager.git
   cd task-manager
   ```
2. Open `index.html` in your browser.

   Or, for a local development server, run:
   ```bash
   python -m http.server 8000
   ```
   Then visit [http://localhost:8000](http://localhost:8000).

## 💾 Where are my tasks saved?

Daymark stores task data in your browser's local storage. There is currently **no account, backend, or cloud sync**, so tasks are specific to the browser and device where you created them. Clearing that browser's site data can remove saved tasks.
